## 1. ผลิตภัณฑ์

เว็บจองรถพร้อมคนขับในเชียงใหม่ ลูกค้าวางทริปบนแผนที่แล้วเห็นราคาทันที 4 แบบ
(เหมาชั่วโมง เหมาวัน เหมาทริป ขาเดียว) ระบบบอกแบบที่คุ้มที่สุด ทีมงานรับงาน
เลือกคนขับเอง แล้วส่งลิงก์รายละเอียดงานให้ลูกค้าและคนขับ ลูกค้ามีทั้งคนไทยและต่างชาติ

### บทบาท

| ใคร | เข้าระบบ | ทำอะไร |
|---|---|---|
| ลูกค้า | ไม่ล็อกอิน · ลิงก์งานมีโทเคนลับ | วางทริป จอง ขอราคา จ่ายมัดจำ ดูลิงก์งาน จองขากลับ รับ push |
| คนขับ | ไม่ล็อกอิน · ลิงก์งานมุมมองคนขับ (โทเคนแยก) | ถ่ายรูปรับ-ส่ง เช็กอินรายจุด แจ้งยอดค่าน้ำ ปิดงานพร้อมเงินที่รับ |
| ทีมงานหลังบ้าน | อีเมล + รหัสผ่าน | ตามสิทธิ์ (RBAC): งานเข้า เสนอราคา จัดคนขับ กฎราคา จุดหมาย ค่าน้ำ การเชื่อมต่อ ทีมงาน |
| เจ้าของ | อีเมล + รหัสผ่าน | ทุกอย่าง + โอนความเป็นเจ้าของ |

## 1b. โครงสร้าง (round 1b — เจ้าของเลือกเอง)

- **Tenancy: บริษัทเดียว** → ไม่มี `org_id` ในตารางใด ไม่มี onboarding / demo tenant / `is_sample`
- **สิทธิ์: RBAC เต็ม** (เลือกหลังจากรับทราบว่าเพิ่ม 3 หน้า 3 ตาราง และชุดทดสอบของตัวเอง)
  → `roles` · `permissions` · `role_permissions` · `staff_invites` · `app_settings.owner_id`
  → เชิญทีมงานทางอีเมล ตั้ง role ต่อคน แก้สิทธิ์ของ role ได้ โอนความเป็นเจ้าของ
  → RLS ทุกตารางเรียก `public.has_perm('<key>')`
- **ล็อกอิน: อีเมล + รหัสผ่าน เฉพาะทีมงาน** · คนขับและลูกค้าใช้ลิงก์โทเคน (ไม่มี PIN, ไม่มี LINE Login)
  → ไม่มี `PIN_PEPPER` ไม่มี `/api/pin-login` ไม่มีตาราง `login_attempts`

## 2. ดีไซน์

- ชุดสีที่เลือก: **แบบ A โครัล × เซจ** (แบบ B ถูกลบออกจากเดโม่แล้ว)

- ค่าสีทั้งหมดคัดลอกตรงจาก `:root` / `:root.dark` ของเดโม่ลง `src/app/globals.css`

## 3. หน้าจอ

สาธารณะ (ไม่ล็อกอิน, สองภาษา ไทย/EN)
- `/` วางทริป: แผนที่โซนราคา ทริปแนะนำ จุดตามหมวด แวะรายทางพร้อม ±฿ ราคา 4 แบบ ขั้นจอง/ขอราคา มัดจำ
- `/j/[token]` ลิงก์งาน: สถานะ ขั้นตอน คนขับ กำหนดการ ราคา กล่องเสนอราคา+นับถอยหลัง ขากลับ
- `/j/[token]` มุมมองคนขับ (โทเคนคนขับ): รูปรับ-ส่ง เช็กอิน ค่าน้ำ ปิดงาน

หลังบ้าน (`/admin/*`, ภาษาไทย)
- งานเข้า · เสนอราคา · จัดคนขับ · ปฏิทินคนขับ (เฟสหลัง) · กฎราคา (รวมโหมดเสนอราคา ขากลับ ระยะจริง ค่าน้ำ)
- จุดหมาย · คนขับและรถ · การเชื่อมต่อ (LINE OA, Stripe, Beam, ตรวจสลิป, routing, PromptPay) · ทีมงานและสิทธิ์
- nav: desktop sidebar ↔ mobile bottom nav 5 ช่อง (งาน · คนขับ · ปุ่มกลาง "สร้างงานแทนลูกค้า" · เสนอราคา · เพิ่มเติม = bottom sheet)

## 4. ฟีเจอร์ v1 / เฟสหลัง

**v1 (เจ้าของเลือก — รวมทุกตัวที่แนะนำให้เลื่อน)**
- วางทริปบนแผนที่ (MapLibre + OSM) · ราคา 4 แบบ + คุ้มสุด · แวะรายทาง ±฿ อัตโนมัติ · เตือนทริปเกินวัน
- ระยะทางถนนจาก routing API (เมื่อตั้งค่าแล้ว) ซ้อนใต้ค่าวัดจริงรายช่วง · ค่าประมาณเส้นตรงเป็นชั้นสุดท้าย
- โหมดเสนอราคาตามช่วงวัน + push แจ้งราคา + นับถอยหลังมัดจำ + หมดเวลาอัตโนมัติ (pg_cron)
- มัดจำ: PromptPay QR + แนบสลิป + **ตรวจสลิปอัตโนมัติ** · **Stripe** · **Beam** (บัตร / e-wallet)
- **ส่ง LINE อัตโนมัติ** ผ่าน LINE OA (ยืนยันงาน ลิงก์งาน เสนอราคา) + web push + ข้อความให้คัดลอกเมื่อยังไม่ตั้ง LINE
- หน้า **การเชื่อมต่อ**: แอดมินกรอก LINE channel, Stripe, Beam, ผู้ให้บริการตรวจสลิป, routing, PromptPay ID เอง · คีย์ลับเก็บใน Supabase Vault
- ลิงก์งานลูกค้า/คนขับ · รูปรับ-ส่งบังคับ · เช็กอินบันทึกเวลาจริงรายช่วง · ค่าน้ำรายจุด + แจ้งยอดซื้อ
- ข้อเสนอขากลับอัตโนมัติหลังปิดงานขาเดียว
- เลขจอง `YYYYMM` + ลำดับ 3 หลัก ไม่มีขีด (เช่น 202610118)
- ทีมงาน + RBAC เต็ม
