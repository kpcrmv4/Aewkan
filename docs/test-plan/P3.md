# P3 — ลิงก์งาน (`/j/[token]`) · acceptance matrix

Worker C · branch `feat/p3-job-link`. Every row runs on both Playwright projects (desktop and phone, 412 px) unless the layout column says otherwise.
Spec files: `tests/e2e/p3-customer.spec.ts` (customer audience, serial after the driver flow created the data), `tests/e2e/p3-driver.spec.ts` (driver audience, the real job life cycle), `tests/e2e/p3-refusals.spec.ts` (negative rows), `tests/e2e/p3-return-api.spec.ts` (return route); unit rows in `tests/unit/p3-*.test.ts`.
Data is created through the staff account under RLS (customer name `E2E P3 <run id>`), links through `rpc('issue_job_link')`; cleanup sets the bookings to `cancelled` and revokes the links.

Result column: `pass` / `NOT RUN: <reason>` is filled in by the final report, not here.

| ID | Case | Expected |
|---|---|---|
| P3-60 | customer token calls `job_start` | PostgREST error `driver_only`; booking status unchanged |

| P3-63 | `job_start` with no pickup photo | error `pickup_photo_required`; status stays `assigned` |
| P3-64 | `job_finish` with no drop-off photo | error `dropoff_photo_required`; status stays `traveling` |
| P3-65 | `job_finish` on an `assigned` booking (photo present) | error `not_traveling` |
| P3-66 | `job_checkin` while `assigned` | error `not_traveling` |

| P3-68 | `job_start` twice | second call error `not_assigned` |
| P3-69 | unknown token calls any action | error `link_not_found` |
| P3-70 | error codes in the UI | each of `pickup_photo_required`, `not_assigned`, `not_traveling`, `dropoff_photo_required`, `sale_required`, `link_not_found`, `driver_only` maps to Thai and English copy (unit) |

## Return route `POST /api/jobs/[token]/return`

| ID | Case | Expected |
|---|---|---|
| P3-80 | unknown token | 404 `link_not_found` (identity before body) |
| P3-81 | driver token | 404 (customer audience only) |
| P3-82 | customer token without an offer | 404 |
| P3-83 | valid offer, malformed body | 422 `validation` |
| P3-84 | valid offer and body, `SUPABASE_SECRET_KEY` missing | 503 `server_not_configured` |
| P3-85 | valid offer and body, key present | 200 `CreateBookingResponse`; return booking `awaiting_deposit`, `parent_booking_id`, `return_discount_pct`; `return_offers.return_booking_id` set; `NOT RUN` here without the key |
| P3-86 | offer dismissed / already booked / `valid_until` passed | 404 / 409 as the unit rows below show (authorize refuses) |
| P3-87 | destination not pickup-capable or equal to the origin | 422 `bad_destination` |
| P3-88 | price is recomputed on the server | unit: `buildReturnBooking` ignores any client price, totals equal `returnQuote` |
