# P2b — ตั้งค่าหลังบ้าน: กฎราคา · จุดหมาย · ระยะจริง · ค่าน้ำ (worker D)

ขอบเขต: `/admin/pricing` (กฎราคา · ค่าน้ำ · ประวัติเวอร์ชัน), `/admin/places` (จุดหมาย · ระยะจริง), routing adapter และ API ของหน้าเหล่านี้
ผู้ใช้ทดสอบ: บัญชีทีมงาน role `e2e_all` (ทุกสิทธิ์) จาก `E2E_STAFF_EMAIL/PASSWORD` · ข้อมูลทดสอบสร้างผ่าน RLS ขึ้นต้น `E2E P2B` และจบ spec ด้วยการซ่อน (`is_hidden`) / ลบเท่าที่สิทธิ์อนุญาต (ตาราง places ไม่มี delete → ซ่อนแทน — L-002)
การเผยแพร่กฎราคาใน E2E: เผยแพร่ **สำเนา JSON เดิมทุกตัวอักษร** หมายเหตุ `E2E P2B` เพื่อไม่ให้ราคาจริงเปลี่ยน (เพิ่มเลขเวอร์ชัน 1 รุ่นต่อรอบ)
สถานะ: `U` = vitest · `E` = Playwright (desktop + phone) · ชื่อ test ขึ้นต้นด้วย ID ในตาราง
