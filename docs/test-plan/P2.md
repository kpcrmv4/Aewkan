# P2a — หลังบ้านงาน (worker B)

ขอบเขต: งานเข้า (`/admin/jobs`, `/admin/jobs/[id]`), เสนอราคา (`/admin/quotes`), จัดคนขับ (`/admin/assign`), คนขับและรถ (`/admin/drivers`) และ API ของหน้าเหล่านี้
ผู้ใช้ทดสอบ: บัญชีทีมงาน role `e2e_all` (ทุกสิทธิ์) จาก `E2E_STAFF_EMAIL/PASSWORD` · ข้อมูลทดสอบสร้างใน spec ผ่าน RLS (`customer_name` ขึ้นต้น `E2E P2 ` + run id) และจบ spec ด้วยการตั้งสถานะ `cancelled`
สถานะ: `U` = vitest · `E` = Playwright (desktop + phone) · ชื่อ test ขึ้นต้นด้วย ID ในตาราง
