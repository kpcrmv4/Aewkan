- R-001 · P0 · 2026-10-21 · Ruling: คีย์ของ LINE OA, Stripe, Beam, ตรวจสลิป, routing และ PromptPay ID เก็บผ่านหน้า "การเชื่อมต่อ" ลง Supabase Vault ไม่ใช่ env — เพราะ: เจ้าของขอให้ตั้งค่าเองได้จากหลังบ้าน และ loop ไม่ต้องรอคีย์เหล่านี้ — ถ้าผิด: ย้ายไป env ได้โดยเปลี่ยนแค่ `src/lib/integrations/secrets.ts`
- R-002 · P0 · 2026-10-21 · Ruling: ตรวจสลิปใช้ adapter กลาง รองรับ SlipOK และ EasySlip ให้เลือกในหน้าการเชื่อมต่อ ค่าเริ่มต้น SlipOK — เพราะ: เจ้าของไม่ได้ระบุผู้ให้บริการ และสองเจ้านี้ใช้กันแพร่หลายในไทย — ถ้าผิด: เพิ่ม adapter ใหม่หนึ่งไฟล์
- R-003 · P0 · 2026-10-21 · Ruling: routing API ใช้ OpenRouteService (มี free tier) ผ่าน adapter เดียวกับ Google Routes ค่าเริ่มต้น ORS · ผลที่ได้ cache ลงตาราง `segments` (source = routing) — เพราะ: เจ้าของไม่ได้ระบุผู้ให้บริการ — ถ้าผิด: สลับ provider ในหน้าการเชื่อมต่อ
- R-004 · P0 · 2026-10-21 · Ruling: ลำดับความแม่นของระยะทาง: ค่าวัดจริง (driven) > ค่าเฉลี่ยเช็กอิน (checkins, ≥3 ครั้ง) > routing > เส้นตรง × ตัวคูณถนน — เพราะ: ตรงกับที่เจ้าของขอให้ขับวัดจริงแล้วใส่โปรแกรม — ถ้าผิด: ราคาเพี้ยนในช่วงที่ข้อมูลน้อย
- R-005 · P0 · 2026-10-21 · Ruling: ราคา กฎ และค่าน้ำตั้งต้นใช้ตัวเลขจากเดโม่ (rule set v1) เป็นค่าชั่วคราว — เพราะ: เจ้าของยังไม่ได้ให้ราคาจริง — ถ้าผิด: เจ้าของแก้ในหน้ากฎราคาแล้วบันทึกเป็นเวอร์ชันใหม่
- R-007 · P0 · 2026-10-21 · Ruling: จุดรับที่อยู่บนทางภูเขา (เช่น ปาย) คิดค่าทางภูเขาเหมือนจุดแวะ — เพราะ: ขากลับปาย→เชียงใหม่ต้องราคาเท่าขาไป (unit test จับได้ว่าต่างกัน ฿300) — ถ้าผิด: ลูกค้าที่รับจากดอยจ่ายเพิ่ม ฿300 ต่อทริป
